# DevLink 🚀

Uma plataforma moderna para conectar desenvolvedores e compartilhar projetos.

## 📋 Sobre o Projeto

DevLink é uma aplicação React que permite aos desenvolvedores:
- Conectar-se com outros profissionais da área
- Compartilhar portfólios e projetos
- Fazer networking na comunidade dev
- Descobrir oportunidades de colaboração

## 🛠️ Tecnologias Utilizadas

- React
- CSS3
- HTML5
- JavaScript

## 🚀 Deploy

Este projeto está configurado para deploy automático no Netlify.

### Configurações de Deploy
- **Build Command**: Não necessário (projeto já buildado)
- **Publish Directory**: `.` (diretório raiz)
- **Redirects**: Configurado para SPA (Single Page Application)
